# Code of Conduct

OpenFlow follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and focus on what is best for the community. Harassment, personal attacks, discriminatory language and publishing others' private information are not acceptable.

## Enforcement

Report unacceptable behaviour privately to the maintainers through a GitHub private security advisory on this repository, or by contacting the maintainer through their GitHub profile. All reports will be reviewed promptly and kept confidential. Maintainers may remove, edit or reject contributions, and temporarily or permanently ban contributors who break this code.
